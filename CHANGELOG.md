# Changelog

## 1.0.0

Initial stable version of Async ORM Kit.

- SQLAlchemy-native asynchronous models, managers, validation, and caller-owned transactions.
- Lazy QuerySets with filtering, projections, relationship loading, pagination, and streaming.
- Typed expressions, grouped annotations, correlated subqueries, set operations, CTEs, and windows.
- PostgreSQL JSONB/ARRAY operations and dialect-aware conflict handling.
- Optional FastAPI, Alembic, and async-storage-kit integrations.
- Query profiling and bounded, parameter-safe diagnostics.
- Reproducible dependency locking, strict documentation builds, and distribution validation.
- Complete runtime statement and branch coverage enforced at 100%.
- Distributed under the MIT license.
